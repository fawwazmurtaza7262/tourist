# Tourist — static/SSR travel website

A simple, maintainable website for showcasing destinations, itineraries, and travel tips.

## Key features
- Destination pages with images and descriptions
- Search and filtering by region, type, and budget
- Itineraries and day-by-day plans
- Responsive, accessibility-minded UI
- SEO-friendly routes (static or server-rendered)
